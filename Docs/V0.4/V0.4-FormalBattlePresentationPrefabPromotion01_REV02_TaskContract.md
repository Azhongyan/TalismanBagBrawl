## 11. Failure / Edge Cases

- Provider 未 bind：fail-closed，精确诊断，不播放伪来源。
- Cue 缺 `sourceItemInstanceId`：fail-closed，不从 roster/sourceId 反查。
- 相同 ItemDefinition 的多个实例：只按 cue 的 instance identity 命中；0 或 >1
  binding 均拒绝。
- Move/rotation/re-entry：每个 accepted event 重新查询当前 binding，不缓存旧
  RectTransform。
- Pause/reset/disable：清理 pending cue 与 accepted source visuals，unbind 幂等。
- Grammar key 缺失/重复：Profile validation 失败；不回退任意颜色。
