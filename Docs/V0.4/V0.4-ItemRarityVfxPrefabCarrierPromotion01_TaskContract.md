## 9. Required Behavior

1. 输入权威 Artwork Sprite 与 `rarityKey` -> 从 Sprite Alpha 产生轮廓/渐变/软泛光；不得描边卡片矩形背景或占格层。
2. `white/green/blue/purple/orange` -> 只选择 Profile 中相应共享表现档；不得从 itemId、FaMen、isLit、Build、Combat Cue 推断。
3. Unknown/空 rarity、空 Sprite、缺 Profile/Material -> fail-closed，VFX 清空/不可见，不影响调用方。
4. Prefab 内所有 Image/RawImage `raycastTarget=false`；兼容 UGUI Mask/RectMask2D/Stencil，不创建输入阻挡。
5. Prefab 层级全部 authored；Runtime 禁止 `new GameObject`、`Instantiate`、`GameObject.Find`、`RuntimeInitializeOnLoad`、Scene finder 或 final hierarchy fallback。
6. 不使用 `new Material`；五品阶复用 Profile 中的共享 Material，多个实例不随启用/清理增长 Material 数。
7. `Apply` 可重复调用，Sprite/rarity 切换不残留旧 Alpha、旧材质或旧颜色；`Clear` 幂等。
8. 常驻效果只表达品阶身份；本包不得包含 Trigger、Attack、Impact、Formation、Lit 或 Build 动画入口。
9. Profile 参数保持可替换和保守；本包不宣称五品阶最终美术调优完成。

## 10. Failure / Edge Cases

- 缺 Sprite/rarity/Profile/Material：关闭效果并返回失败，不抛异常。
- Unsupported rarity：关闭效果，不回退为 LiHuo/TaiBai 或默认橙色。
- Disable/Enable/Domain Reload：不创建重复层、不泄漏 Material、不修改外部 Image。
- Mask/Stencil 不兼容或出现矩形泄漏：本包失败，不能以“P2再修”为由放行。
