## 4. First-clear / Replay Flow

### 4.1 进入

- 从正常可点击的 WorldMap stage 进入时创建一个 in-memory Item/Battle/Reward chain；
- 初始 stage 可以是 fresh `1-1` 或任意 Cleared replay；
- WorldMap 未完成 stage 永不因 completion 邻接自动解锁。

### 4.2 首次通关 N < 5

`accepted realtime victory -> Reward resolver -> exact accepted grant -> Item entitlement acceptance once -> completion MarkCleared once -> 显示精确掉落身份 -> 新实例加入动态 Tray 且旧实例保持可见 -> 打开重摆 -> 关闭重摆 -> 同一 Unified Scene 启动 N+1`。

### 4.3 首次通关 1-5

执行相同奖励、入库、完成记录与重摆；关闭重摆后返回 WorldMap。

### 4.4 Cleared replay

- Reward 以 completion proof 判定 `RepeatChallengeOnline`；
- 合法 replay victory 仍产生新奖励机会；
- 同一 StageClear/claim 重试零重复；
- replay 奖励与重摆完成后返回 WorldMap，不自动连续推进，不覆盖 completion 事实。

### 4.5 Fail closed

defeat、quit、rejection 或链中任一步失败：不写 completion、不发奖励、不入库、不伪造后续。重复 victory/claim/clear 幂等；动态 Board/Tray 与 source provider 必须保持上一 accepted snapshot，不得部分覆盖旧实例。

clearSequence 仅在当前 in-memory Reward session 中从 1 递增。
