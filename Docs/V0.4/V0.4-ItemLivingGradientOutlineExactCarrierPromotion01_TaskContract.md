## 9. Required Behavior

1. `Apply(authoritative Sprite, authoritative rarity)` -> 七层全部绑定同一 Sprite alpha/比例，选择对应 rarity 的共享外观；不得描边 Card 矩形或占格背景。
2. 常驻态 -> contour + persistent halo + whole-body emission + inner glow + outer halo + environment spill 同时存在，以旧 `Runtime_00` 的重叠、呼吸、亮带语言为忠实参考；不是只把五层亮度调高。
3. `PlayTrigger(unscaledNow)` -> 独立 trigger layer 在约 80ms 点燃、约 250ms 扩散、约 550ms 回稳；同时按旧效果语法增强整图发光、内外泛光与环境溢光，结束后精确回到当前 rarity 的常驻态。
4. trigger 可以重复调用且不会生成新对象或新 Material；后一次合法 trigger 采用确定性重启/刷新，不产生重叠残留。
5. `Apply` 切换 Sprite/rarity -> 所有七层同步更新；旧 Sprite、Material、Alpha、Scale、trigger 状态全部清除。
6. `Clear`、Disable、unbind、reset -> 七层幂等清空，trigger inactive，尺度回零，无 MissingReference、重复层、实例增长或材质增长。
7. 所有 Graphic `raycastTarget=false`、`maskable=true`，兼容 UGUI Mask/RectMask2D/ScrollRect/Stencil；不得改外部 Card RectTransform、Artwork、pivot、mask、drag/rotate/placement。
8. Shader 必须保留正式 UGUI/Stencil/ColorMask/AlphaClip，并补足被接受效果所需的 blend、outline radius、whole-body、flow/noise/trigger 参数；不依赖全屏 Bloom、真实 Light 或 Editor-only 资源。
9. Runtime 只驱动 authored hierarchy 和 Profile 共享资源；禁止 `new GameObject`、`Instantiate`、`new Material`、`GameObject.Find`、RuntimeInitialize bootstrap 或 Resources 中的 DevOnly 依赖。
10. CausalSourceProxy/CausalRibbon 与 Combat Impact/audio 仍是独立 formal carrier；本包既不删除也不把它们算作七层能力。

## 10. Failure / Edge Cases

- Sprite/rarity/Profile/material/层引用缺失：fail-closed，七层清空，不抛异常，不回退到某个 itemId/BuildFamily。
- unsupported rarity：清空并返回 false，不默认橙色或离火。
- trigger 在未 Apply、已 Clear 或已销毁对象上调用：安全返回，不产生层或状态。
- Domain Reload/重复 Enable/Disable：不创建重复层、不增长 Material、不保留 stale trigger。
- Mask/Stencil 出现矩形泄漏或 Card 输入被遮挡：本包失败，不得推给 P2。
- 当前外部 Unity Editor/Lock 存在：禁止写项目与启动 Unity；仅可只读审计。不得等待、轮询、终止或清理外部进程。
