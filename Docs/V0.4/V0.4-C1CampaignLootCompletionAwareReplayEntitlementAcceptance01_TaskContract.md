## 9. Mandatory Scenario Matrix

1. Signed completion prefix `1-1,1-2,1-3,1-4`.
2. Fresh Reward session, replay `1-4`, local clear sequence/accepted ordinal 1,
   mode `RepeatChallengeOnline`, exact signed pre-op prefix.
3. Then legitimate first clear `1-5`, local clear sequence/accepted ordinal 2,
   mode `FirstClearOnline`, exact updated signed pre-op prefix.
4. Exact retries of each accepted grant are idempotent no-ops.

- prefix `1-1..1-3` with direct/gapped `1-5` first clear;
- Repeat mode for a stage absent from the signed prefix;
- FirstClear mode for an already-completed or non-first-missing stage;
- v1/missing lineage;
- proof, session specification, prefix, stage, mode, run session,
  StageClear, grant, claim, dedupe, materialization, entitlement, Item instance,
  or canonical tamper;
- stale command token/generation/prior signature;
- I001/I031/non-Pool15/non-white identity.

Every rejection must preserve the exact prior session/roster/Board/Tray/
history references, counts, and canonical signatures.
