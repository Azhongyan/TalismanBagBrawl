## 9. Required Behavior

1. 碎骨附身者五组状态优先以“重选帧 / 重定时 / 限制重启”提升可读性：
   - Idle 约 `0.9–1.2s`
   - Hit 约 `0.18–0.30s`
   - Attack 约 `0.65–0.85s`
   - Skill 约 `1.0–1.4s`
   - Death 约 `0.8–1.2s`，末帧保持或安全消退
2. 存活时 Hit 反馈优先于 Attack / Skill / Idle；HP 归零后 Death 立即成为终态并锁定。
3. 连续短时间受伤不得每次都重启完整长 Hit，导致敌人永远无法 Attack / Skill；应基于真实 cue / sequence 做去重与合理覆盖。
4. Attack / Skill 的实际伤害结算必须对齐既有 Battle resolve / accepted result；动画不得自行算伤害，不得等待动画完成后再释放真相。
5. 目标描边只消费 `selectedTargetEnemyInstanceId`；必须是透明轮廓描边 / 受控泛光，禁止矩形框、整图白块、修改原图像素。
6. 目标切换即时转移；死亡、换波、无目标时即时清理；非目标不得伪造高亮。
7. Item / Battle 对敌人的真实 HP / 护壳变化，只能在对应 enemyInstanceId 的槽位附近飘字；duplicate / stale / zero-delta 不得重复飘。
8. 敌人 Attack / Skill 对玩家造成的真实 HP / 护盾变化，只能在玩家权威 receiver 附近飘字；不得从动画帧猜数。
9. 浮字必须复用场景中用户已调好的 TMP 对象 / 样式与 `MFLangSongJianYuan-Regular SDF`；不得运行时另造“小字 debug float”。
10. 直接 HP 用既定红色渐变；护盾 / 破盾用黄 / 金渐变；本包不扩 AP / 资源类浮字。
11. Runtime 不得覆盖 authored RectTransform；若需运行时对象，只能挂在 owner-owned runtime root，不得改用户槽位位置 / 大小 / 层级。
12. 同包并入用户范围修正：撤除当前粗制的两类表现：
   - 道具从棋盘 / 道具位置飞向敌人的发射物、弹道、travel projectile / trail；
   - 命中敌人后的现有火焰爆炸 / 火焰 Impact VFX。
13. 上述撤除只影响视觉播放与对应 runtime-only pooled 视觉残留；不得修改真实 Item request、Battle accepted / application、伤害数值、目标选择、敌人 HP / 护壳、关卡推进。
14. 撤除粗临时 travel / impact 后，必须保留：
   - 道具源位置的短促触发提示 / 亮起（若其本身不依赖被撤对象）
   - 敌人 Hit 动画
   - 选中描边
   - 实际伤害飘字
15. 清理旧 travel / impact 后不得留下空池反复生成、MissingReference、残影、隐藏矩形，也不得误删品阶描边、道具源反馈、音频或用户已调 TMP 浮字。
16. 测试对象仍是第一怪“碎骨附身者”；本次只替换其 presentation animation source，不改变其身份与战斗真相。
17. 第一怪把现有权威 Idle / Attack / Hit / Skill / Death 事件映射到 `d1_3` 的序列帧；不得新增测试面板、不得新增敌人状态 owner。
18. 允许第一怪独立校准 sprite footprint、anchor、fps 和必要的状态回零；Runtime 仍不得覆盖 authored geometry。
19. Hit 必须在真实受伤事件时立即可读；Attack / Skill / Death 按现有事件播放，Idle 回落稳定；不要用额外屏闪、粗糙投射物或大面积 VFX 掩盖素材质量。
20. 若 `d1_3` 缺某个状态，只允许明确的静态 / 最近合法状态回退；不得回退回 `di_1` 整套动画来冒充完成。
21. 本 revision 需要在真实 1-1 最短路径中做一次 Fresh Play：两只碎骨附身者均使用 `d1_3` 表现，至少观察稳定 Idle、一次真实 Attack、一次真实 Hit、一次 Death，并保持描边 / 伤害飘字 / 多怪身份不串位。

## 10. Failure / Edge Cases

- 缺资源 / 空 clip：fail-closed 到安全静态显示，不得崩溃
- 重复 cue / 重复 settlement：必须按 eventId / sequence / resetGeneration 去重
- 快速切目标：描边不能串位，旧 target 状态必须清干净
- 多怪同时受伤：数字不能串到别的 enemy slot
- 敌人死亡后继续收到旧 cue：不得从 Death 回到 Idle / Hit
- Reload / Fresh Play：不依赖 hot reload 比较；验收只看 fresh play
- 若玩家侧真实 damage-result outlet 缺失：只允许新增最薄只读 presentation envelope，不得顺手改 battle 结算
