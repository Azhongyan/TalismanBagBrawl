## 5. Producer and Balance Gate

### Producer decision

- Classification: `FOUNDATION_BLOCKER`
- Meaningful choice: 玩家把不同 Item 放置并点亮后，正式 Battle 必须只执行这些 active Item。

- Continue-building desire: 新获得 Item 能改变下一场结果，形成重新摆放动机。

## 11. Required Behavior

1. Adapter validates the immutable Item snapshot, then selects active Pool15 sources only from rows where `isPlaced == true && isLit == true`. Tray and placed-unlit rows are excluded from active facts without invalidating a valid entitlement snapshot.
2. Invalid/unknown/duplicate identities, stale canonicals, unsupported rarity/descriptor/profile fields or conflicting active facts fail closed. `UNKNOWN`, `UNSUPPORTED`, `NOT_EXECUTED` and unit conflict never become zero.
3. Session owns the formal event envelope: event identity, battle time, trigger, satisfied conditions, source membership, target identity, target scope, percentage base and current live state. Callers cannot directly inject an applied delta or cue.
4. Only active sources whose immutable trigger/condition match the accepted formal event may enter Foundation execution. A Tray/unlit/unknown source must never appear in application ledger, cue ledger or live-state delta.
5. Foundation results apply atomically to Session state. If one requested source rejects, the event causes no partial state mutation and emits a rejection diagnostic only.
6. Preserve native domains exactly: `point / stack / count / flat / basisPoint / turn`. A native `turn` may be stored and consumed only as a discrete Battle turn counter; it must never be converted to milliseconds or seconds.
7. The five families must have shared formal state consequences, not item-specific branches:
   - `DIRECT_TEMPO`: resource/status/damage modifier state;
   - `TARGET_SPREAD`: deterministic extra/converted target-state application;
   - `GUARD_SUSTAIN`: player guard/heal/extra-trigger state, with guard absorbing enemy damage before HP when applicable;
   - `ENEMY_CONTROL`: target break/cast-progress/targeting control state;
   - `POSITIONAL_ADJACENCY`: resource cost, guard or cooldown-turn state derived from accepted Item layout conditions.
8. Percentage operations use Foundation fixed-point and the Session-provided authoritative base. Missing base rejects; no inferred base.
9. Same-trigger sources resolve in stable source identity order at `120ms` increments. Session ledger and cue ledger preserve trigger time and resolve time even if the outer tick advances beyond both.
10. Every accepted application/cue exposes source item, family, variant, trigger, condition, operation, target, requested/applied amount, native unit, target before/after, candidate profile identity/maturity, trigger time, resolve time, cue identity and canonical signature.
11. Existing I001/I002 direct-damage cadence remains unchanged. I002 `Refund nian` is an additional descriptor effect and must never replace, duplicate or reinterpret authoritative I002 direct damage `28 / 2s`.
12. Existing stage 1-1 constraint and stage 1-2 valid `0 / 1 / 2` active admission, Tray/unlit exclusion, real defeat, lifecycle, reset, refresh and terminal behavior must not regress.
13. No formal Host/Mainline call is added in this package. The Session integration is callable from its existing formal Adapter but remains unassembled in the player route until downstream packages supply Pool15 inventory facts and route events.

## 12. Failure / Edge Cases

- Foundation/profile/pool signature drift: reject integration start/event.
- Candidate maturity not `CANDIDATE` or `entersFormalFlow` silently changed: reject.
- Missing trigger, condition, target, percentage base or native unit: reject without mutation.
- Duplicate event/source: idempotent rejection; state and ledger unchanged.
- Stale Session token/generation/reset: reject.
- Event resolves after terminal, during pause without authorized refresh, or at stale time: reject.
- Target dies before delayed source resolve: deterministic retarget according to existing stable actor order, or explicit rejection if descriptor target scope cannot retarget; never target a dead actor silently.
- Overflow/fixed-point boundary: reject atomically.
- Unsupported formal semantic mapping: `UNSUPPORTED_FORMAL_EFFECT_MAPPING`; do not add a special-case item executor.
