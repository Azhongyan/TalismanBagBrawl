## 11. Required Battle Rules

1. Product context must be exactly `CAMPAIGN_NORMAL_LV1`.
2. Valid stages are only `1-1` and `1-2`.
3. Valid encounter variants are only:
   - `campaign.normal.lv1.encounter.c1.1-1`
   - `campaign.normal.lv1.encounter.c1.1-2`
4. Resolve Item projections through `C1Lv1StarterItemBaselineCatalog`.
5. Resolve Enemy balance through `C1Lv1EarlyEncounterBalanceCatalog`.
6. Stage `1-1` request must contain `I001@white` lit.
7. Stage `1-2` request must contain `I001@white` lit and `I002@white`
   either lit or unlit.
8. Unlit Item rows produce no player damage events and must be recorded as
   not executed, not as zero-damage accepted applications.
9. Lit Item rows start at their authoritative cooldownSeconds and repeat at
   the same interval.
10. Enemy attack waves start at 4.5 seconds and repeat every 4.5 seconds.
11. Same-tick order is `player_then_enemy`. If the player-side application
    defeats the final enemy at the same timestamp, the same-tick Enemy attack
    does not apply.
12. Enemy attack wave is one accepted player-damage application per wave for
    the encounter, not one per visible actor.
13. Actor target order is stable actor row order from the Enemy balance
    profile. Shield and skill are disabled for this P0 profile.
14. Overkill damage from one accepted Item application carries forward to the
    next legal actor in stable actor order until the application is exhausted
    or all actors are defeated. This is required to preserve the accepted
    total-HP traces while still using real actor rows.
15. Starting Battle player max/current HP is `100/100` for this
    `CAMPAIGN_NORMAL_LV1` application package only. Do not write formal player
    stats or Save.
16. Reset/unbind increments generation or invalidates pending events so stale
    requests cannot apply after a reset, reload or context mismatch.
