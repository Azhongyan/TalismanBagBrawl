## 12. Required Behavior

1. Resolve the released Pool15 snapshot and fail closed unless schema, product context, pool signature, source catalog signature, exact 15 identities and exact five families match.
2. Consume immutable descriptor fields by reference/clone; never re-declare Item identity, shape, display name, family membership or cue identity as Battle truth.
3. Load the Battle candidate profile by `baseItemId`; profile amount/unit must match section 10 and remain `CANDIDATE / entersFormalFlow=false`.
4. Route every item through exactly one of five reusable family executors. Do not create item-specific executor classes or switches that embed 15 bespoke systems.
5. Execute only after a matching trigger and condition context is supplied. Missing/unknown/unsupported trigger, condition, target, amount or unit must return a rejection diagnostic, not a zero-delta success.
6. Preserve native domains: point, stack, count, flat, basisPoint and turn. `turn` produces a native turn delta for a later Battle clock adapter; it is not milliseconds in this package.
7. Apply deterministic fixed-point arithmetic for percentage operations; define rounding once and test it.
8. Same-trigger accepted sources resolve at `baseBattleTimeMs + sourceOrdinal * 120ms`, ordered by stable source identity. Ledger sequence and cue identity must be unique, deterministic and source-attributable.
9. Each accepted result exposes source item, family, variant, trigger, condition, operation, target scope, target identity, requested/applied amount, native unit, trigger time, resolve time, cue identity and canonical signature.
10. Produce a 15-row execution matrix proving every descriptor reaches the shared foundation. Technical fixture execution is not formal runtime evidence.

## 13. Failure / Edge Cases

- Pool/schema/catalog/signature drift: reject whole foundation creation.
- Missing candidate profile: `NUMERIC_PROFILE_PENDING`, never zero.
- Unknown condition/target/unit: reject with explicit diagnostic.
- Duplicate source/event: reject idempotently; no double application or duplicate cue.
- Same timestamp: stable source order and 120ms staggering.
- Percentage overflow/rounding: checked fixed-point path, deterministic boundary tests.
- Unsupported formal lifecycle: no attempt to bind Session; report `NOT_INTEGRATED`.
- Caller mutation: defensive copies; repeated resolution byte-identical.
